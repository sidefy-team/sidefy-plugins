# 少数派文章评论

读取少数派文章的公开热门评论及每条评论下的回复，并将评论作为时间线事件显示。文章作者的评论和回复为蓝色，其余为红色。点击事件可打开对应文章。备注里写原文和文章链接；回复他人时，会附上对方的上一条内容，不再重复当前回复人。

## 配置

- `articleId`：一个或多个文章 ID，使用逗号、空格或换行分隔。默认是 `114211`，对应 [我做了一个地图壁纸 - Here Wallpaper](https://sspai.com/post/114211)。
- `pageSize`：每页读取数量，范围 1–20。每篇文章最多读取 100 条主评论，评论下的回复也会一并读取。

插件使用少数派网页前端的评论接口，不需要登录 Cookie。文章标题和评论结果按文章 ID 缓存 15 分钟，缓存过期后自动刷新；接口或站点行为变化时可能需要更新插件。
